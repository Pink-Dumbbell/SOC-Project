05

Risk Scoring Engine

OWASP Risk Rating Methodology의 Likelihood × Impact 개념을 참고해 실시간 자동 대응에 맞게 가산점 방식으로 단순화한 자체 채점 체계입니다. 최대 100점.

SCORE = BASE + LIKELIHOOD + MULTI-STAGE + BUSINESS IMPACT + SENSITIVE TARGET + POST-EXPLOITATION

Likelihood

동일 IP 반복 횟수 — 5회↑ +5, 20회↑ +10, 50회↑ +15

Multi-Stage

Kill Chain 연쇄 패턴 (정찰→침투→실행) 감지 시 +10~20

Business Impact

/admin, /api/admin +15 · /login +10 (요청 URL 파싱 기반)

Sensitive Target

Traversal/Inclusion이 /etc/passwd 등 민감 파일 직접 접근 시 +20

Post-Exploitation

whoami, wget, reverse shell 등 실행 흔적 발견 시 +25
